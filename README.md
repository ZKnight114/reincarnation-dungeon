# 轮回冒险公会 · 构筑培养 Demo v14

双击 **轮回地牢.html** 即可离线运行；已打开旧版的页面需要刷新。游戏采用冒险公会主题，沿用原文件名。单文件约 **3 MB**，包含代码、样式、像素物品与角色图像，无外部资源和内嵌字体。

## 源码维护与构建产物

日常修改从 `src/` 开始，不直接编辑自动生成的 `轮回地牢.html` 或 `dist/`。

| 位置 | 用途 |
| --- | --- |
| `src/game.ts`、`src/backpack.ts`、`src/resonances.ts` | 关卡推进、装备摆放与构筑规则 |
| `src/ui.ts`、`src/pack-ui.ts`、`src/archive-ui.ts` | 页面、触屏拖放和冒险者档案 |
| `src/assets.ts`、`src/pixel.ts`、`src/assets/` | 资源地址加载、人物呈现与原始PNG；不在规则模块写base64 |
| `src/*.css` | 可读样式源码；历史层按 `main.ts` 中的顺序加载，修改时注意覆盖关系 |
| `tests/` | 规则、存档、DOM、计算样式和模拟触屏检查 |
| `dist/` | 网页交付版，JavaScript、CSS和图片分开输出 |
| `scripts/standalone.mjs` | 将网页资源嵌入单文件离线版，仅交付版混合资源与代码 |
| 本地 `qa/` | 核查记录；自动检查与真实浏览器实测分别记录，不上传日志与参考视频 |

运行 `npm run format` 整理源码，`npm run format:check` 检查格式，`npm test` 验证逻辑，`npm run build` 完成类型检查、网页构建、离线打包和离线操作验收。构建压缩不改变可读源码。

## GitHub Pages 发布

仓库包含 `.github/workflows/pages.yml`。在 GitHub 仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**，随后在 Actions 中运行 **Build demo for GitHub Pages**，或向 `main` 推送修改。

工作流先运行测试和构建，再发布 `dist/`。部署成功后，Pages 页面及工作流部署记录会显示试玩地址。首次上传源码不等于已经启用 Pages；需要上述仓库配置。在线试玩与本地HTML按不同网址分别保存进度。

## 招募与开局

公会 → 单关地牢页 → 体力招募 → 入会档案与加点 → 两轮六件起始装备 → 整理行囊 → 初始共鸣 → 回合制探险 → 最终整理 → 勇者加入名册。

关卡页默认显示最新解锁的一关，左右箭头、横向滑动或键盘方向键切换已解锁关卡。成功结业解锁下一关，最多二十关。

- 基础招募消耗 **10 体力**，随机战士、法师或盗贼；定向招募消耗 **20 体力**，指定职业。
- 体力上限 **60**，每 **5 分钟恢复 1 点**，离线有效；满体力不积攒额外恢复时间。
- 招募确定身份、职业和四个基础天赋，返回公会或重载后可继续配置，不重复扣费。
- 档案展示四个天赋和攻击、生命、防御、速度四维属性，固定 **12 点**供玩家分配。每点分别增加攻击 2、生命 8、防御 1、速度 1，分完后进入地牢。
- 金币是外部货币，初始 100；本版没有金币消费入口。正常结业奖励 `100 + 关卡编号 × 15`，极限毕业双倍奖励；战斗和关内事件不产出金币。

## 装备与背包

| 职业 | 攻击系列一 | 攻击系列二 | 功能系列 | 一格无分支物品 |
| --- | --- | --- | --- | --- |
| 战士 | 剑重击 | 长枪连击 | 盾牌与耐力 | 勇气徽章 |
| 法师 | 法杖（火焰） | 魔导书（冰霜） | 法袍与法力 | 奥术水晶 |
| 盗贼 | 匕首毒伤 | 弓弩连射 | 皮甲与治疗 | 暗影宝石 |

每职业十种已投放装备：一格一件，二、三、四格各三件。五格装备保留九种定义，暂不进入任何物品池。每件物品使用经确认的固定朝向。同一职业的三／四格系列轮廓区分，只有功能四格采用方形。盗贼三／四格匕首为双匕组合。当前实际形状为单格、二格直线、三格直线、三格 L、四格直线、四格 L、四格方形，已删除 T 形。

开局 **两轮 × 三件全部赠送**，拖入一件仅领取这一件；本轮全部拿完或点击继续才刷新下一轮，战斗胜利后三件掉落也全部归玩家，允许同批出现同名同级装备。掉落有权重参考未满级的当前构筑；前中期匹配模板权重60%，后期80%，第二阶段起有65%机会匹配该目标等级（最高Lv.3），便于合成。掉落与暂放装备共用上方战场区域，显示连续的实际形状；下方为最终 **7×6 背包**或事件历程。起始中央 **15格**，每次战斗胜利沿连续边带开放2格，第14次胜利全部开放，新增格短暂闪光；三个职业的六件起始装备均能排入初始范围。放不下时由玩家取舍，闭格不能放置。

- 点击装备查看详情，只有拖动改变位置，物品朝向固定，不提供旋转；触屏拖动保留抓取格偏移。
- 拖到同名同级装备上合并，最高 **Lv.5**。上方显示栏也支持直接拖动合成，包括起始补给；接收物品保留原位置，原本未入包则合成后仍未入包。目标实际占用格高亮后松手生效，L形空白处不会合成。不使用合并按钮或升级石。
- 覆盖一件物品时，能放下就互换；不能互换时，被覆盖装备移到上方。覆盖多件也会移到上方，不丢失物品。
- 可以拖到上方暂放，取消或越界不改变布局；战斗时不能整理。
- 进入下一小节点时，所有未入包装备自动回收，每件1点，包括战斗掉落、事件奖励、重铸所得和被挤出的装备。已入包或合并后的装备保留。两轮开局补给是出发配置，期间可整理全部六件，确认初始共鸣前回收未入包的起始装备。
- 弃用一件获得 **1 点**，左下角满 **6 点**手动重铸随机装备；右下角为 **1× / 2× / 4×** 倍速，不能弃用最后一件武器。
- 等级不改变形状，属性倍率 **1/1.5/2.1/2.8/3.6**，颜色 **白/绿/蓝/紫/橙**。

## 37 节点培养

开局两轮补给、背包整理和初始共鸣在出发配置中完成，不计入冒险小节点。参考视频前四年的开局／灵宠／初始神通以及第41年的传功不直接复制；本版不投放灵宠、长老、功法、炼合或导师节点。剩余视频第5–40、42年映射为37个节点，顺序保留，事件描述改为西幻主题。

| 节点 | 流程 |
| --- | --- |
| 1–8 | 战斗、剧情抉择、补给、挖宝、月泉 |
| 9 | 第一次晋阶，第二次共鸣选择 |
| 10–16 | 战斗、剧情抉择、宝箱、月泉 |
| 17 | 第二次晋阶，第三次共鸣选择 |
| 18–24 | 月泉、战斗、命运事件、剧情抉择 |
| 25 | 第三次晋阶，Boss守门者，第四次共鸣选择 |
| 26–31 | 完整四共鸣构筑继续战斗、挖宝与成长 |
| 32 | 正常结业，或选择继续挑战极限 |
| 33–36 | 四场极限战斗，敌人生命 ×1.6、攻击 ×1.35 |
| 37 | 最终行囊整理，确认毕业 |

完整路线包含16场普通战斗、3次晋阶、1次补给、1次宝箱、3次挖宝、4次月泉、1次命运事件、6次剧情抉择及结业／结束节点。顶部37个小刻度各对应一个节点，已完成、当前、试炼与极限挑战采用不同样式；具体步数在标题中显示。

三档试炼分别为守望、勇气、英雄。敌人生命倍率 **1/1.35/1.75**，攻击倍率 **1/1.2/1.45**，成长倍率 **1/1.35/1.8**。胜利后提高基础属性，并按生命上限恢复 **25%/35%/45%**，先展示晋阶名称、属性增量和实际恢复量，再点击选择共鸣，最后整理本节点三件装备。试炼使用祭坛、魔力冲击和觉醒光柱表现；觉醒阶段可以保存并恢复，不重复发放成长或装备，失败不发放成长。

剧情抉择包括消耗 **15% 当前生命**换伤害、防御、装备或随机成长，以及治疗/提高生命上限。鲜血祭坛消耗生命换基础属性 Buff；月泉、轮盘可能治疗。普通战斗、等待、整理、合并和重载不会自动回血。

挖宝采用 **4×4 格、12 次挖掘、3 件隐藏装备**，完整揭开物品占用格后才获得装备，允许提前结束。进度和铲子次数随存档保留。

下方区域在完整历程与背包之间切换，战斗和整理显示背包。**所有历程记录保留**，按小节点分组，同一节点的遭遇、结果、收益共用一个关卡标记；新记录追加在下方，超出可见区域的旧记录可上翻。阅读旧内容时不会强制跳回最新，切换背包后恢复此前的位置。出发配置的记录统一在“启程”下。

开始冒险或完成事件后点击底部继续，先播放当前节点历程，再进入战斗或特殊事件弹窗。普通历程按字数停留1.2–2.5秒，晋阶／结业／毕业停留3.2秒，受倍速影响；继续可以提前结束等待。无选择的补给与普通宝箱直接发放三件装备并停在整理状态，不再增加接受弹窗。有风险或选择的事件仍用弹窗。事件完成后必须再次点击继续才推进下一小节点，不自动连续闯关。

上方人物固定朝右探索，背景与地面向左循环移动；装备出现时保持统一尺寸、脚下位置和朝向，在物品后方继续探索，物品优先响应拖动。战斗及事件处理时停止场景前进，战斗显示攻击／受击动作、资源／护盾、实际伤害与吸收数值。三个职业的待机、行走、攻击、受击使用既有样稿生成的简易六帧动作；原图和样稿保留。探索／装备时隐藏战斗血条，人物信息框持续显示当前／最大生命。减少动态效果偏好开启时停用动画。

共鸣框显示图标、贡献／下一阈值、进度条与三档标记；跨档短提示，匹配且激活的共鸣在对应装备发动时短亮。顶部37个刻度区分节点种类；底部保留重铸、继续／战斗主按钮和倍速，暂停／单步放在“⋯”内。背包开放格为亮色，闭格为深色斜纹与叉标，开放区域边缘描金。关内继续采用390×844设计画布按手机视口整体缩放，长弹窗内部滚动；本轮手机实显验收未完成，见验证记录。

## 共鸣构筑

共 **54 项共鸣**，每职业 18 项：三条职业路线与三条物品路线，各有基础、进阶、高阶三个不同名称的共鸣。

| 职业 | 职业路线 | 物品路线 |
| --- | --- | --- |
| 战士 | 重击、连击、守势 | 剑、枪、盾牌 |
| 法师 | 火焰、冰霜、奥术 | 法杖、魔导书、法袍 |
| 盗贼 | 毒刃、连射、暗影 | 刀刃、弓弩、皮甲 |

初始与三次晋阶分别选择一次，每次固定 **三个候选选一个**，最多四项，职业和物品共鸣共用栏位。初始只出现基础共鸣；选择某条路线的基础共鸣后，后续能刷出该路线的进阶或直接刷出高阶。不同名称的共鸣共存，各自占一栏，不替换旧共鸣。后续也保留其他路线基础候选，允许混合构筑。

每项共鸣另外有三档贡献效果，与卡片前置关系分别计算：

**装备贡献 = 实际占格数 × 等级系数（Lv.1–5：1/2/4/8/16）。**

| 类别 | 第一档 | 第二档 | 第三档 | 计入范围 |
| --- | ---: | ---: | ---: | --- |
| 流派（职业） | 12 | 80 | 200 | 当前已装备的本职业装备，含无分支一格物品 |
| 物品类别 | 2 | 8 | 24 | 当前已装备且匹配类别的装备 |

贡献不消耗，同件装备可贡献多个共鸣。上方暂放物品不计入；合并后总贡献保持不变，腾出的空间可加入新装备。低于首档时已选共鸣保留但暂未激活。选择前置不要求贡献档位，获得新共鸣后立即按当前贡献生效。

候选展示类别、路线、前置、当前贡献和三个档位的具体效果。效果包含持续伤害、控制、资源返还、治疗、护盾、反击和追击；追加伤害不递归触发追加攻击，护盾上限、救援与反击次数受限。

## 回合战斗与毕业

双方每回合各行动一次，速度较高者先手，同速勇者先手。回合顺序在当回合固定，减速影响下一回合；死亡立即停止剩余行动。装备采用整数回合冷却：每两回合发动的装备在第 1/3/5 次勇者行动发动，资源不足保持就绪。

功能装备先于武器结算，中毒和灼烧在敌方行动前结算。每场重置资源、护盾和治疗次数，生命跨战斗保留。支持暂停、逐行动推进和展示速度切换。

正常结业与极限毕业均按成功结算。死亡或撤退也保存当前勇者，失败评级最高 B。战力由培养成长、实际构筑和战斗表现组成，评级阈值 **C 450 / B 1100 / A 1900 / S 3000**。

结算首屏突出人物、评级、最终战力、四项共鸣和金币，完整培养档案与最终背包放在详情入口。毕业保存勇者属性、天赋、加点、试炼、共鸣及**最终已装备物品和布局**。装备永久绑定本人，可在结算/公会名册查看，不能转移、售卖、合并或带入新招募；上方未装备物品不进入毕业配置。
