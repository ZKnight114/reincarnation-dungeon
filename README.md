## 培养流程

公会 → 关卡切换 → 招募 → 四天赋与12–16点加点 → 独立典籍选择 → 两轮六件起始装备 → 初始共鸣 → 历程／战斗／事件／整理 → 三次守关晋阶 → 最终整理 → 冒险者结算与金币／公会勋章。

- 基础招募5体力，随机职业；定向招募20体力，指定战士／法师／盗贼。体力上限60，每5分钟恢复1点，离线有效。
- 起始加点12，购买课程后最多16；加点攻击／生命／防御／速度，每点分别增加2／8／1／1基础属性。档案最终属性预览计入当前公会与所选典籍增幅。
- 第一／二／三关常规结业分别18／24／28个节点；第四关起32个。前三次守关始终保留；第一、二关无极限挑战，第三关极限共31节点，第四关起极限共37节点。
- 境界为黑铁、青铜、白银、黄金、秘银、精金、传奇，每级分初／中／高阶。每次守关试炼只推进一小阶，普通战斗和事件不提升境界。境界不由战力评分反推，也不额外重复增加试炼属性或回血。
- 正常结业金币为100＋关卡×15，极限毕业双倍；关内战斗不产生金币。失败与撤退仍保存当前冒险者，失败评级最高B。

## 公会与九本典籍

公会开放1–30级，与本期10关分别推进。每级满足三项累计条件后升级，可连续升至当前可达等级；公会等级只开放单线增益路线，每级3个普通节点，5／10／20／30级各增加一个初始属性点节点。花公会勋章依次购买节点后才生效，移除旧的每级自动5%增幅。满路线攻击＋30／生命＋300／防御＋15，并分别＋30%；初始属性点从12到16，路线总费5630勋章。

勋章仅结算领取，基础奖励随关卡24→76；已通过每次守望／勇气／英雄试炼增加2／4／6。失败只得已过试炼奖励，主动退场得该部分一半，极限完整通关额外给基础奖励50%。三守望第1关30勋章，第10关82。通用增益作用已毕业勇者但不改历史评级，培养中绑定招募时增益；额外加点仅新招募。招募起点改随所选关卡每关增加一小阶，第1关黑铁初→青铜初，第10关黄金初→秘银初。

典籍共九本、每本三阶。加点完成后，在独立的一屏选择页查看人物、当前典籍、效果及九本收藏，可按职业筛选。典籍不限制勇者职业。首次培养每个职业可任选一本免费解锁，确认进入地牢时才消耗赠送资格；以后选择已收集典籍。一局绑定一本和当时的阶位，赋予人物属性与回合自动技能，不占背包或共鸣栏、不贡献共鸣、不接受邻接增幅。毕业保存绑定配置，升级收藏不修改旧冒险者的典籍。

选其他职业典籍后，每件常规战利品与重铸以15%概率使用该典籍对应系列的二至四格物品池，例如战士选焚星秘典可获得法师法杖。起始六件仍属于主职业。跨职业装备可正常摆放、合并、释放技能及保存毕业装备，人物职业与克制不变；物品按自己的标签贡献共鸣，不自动解锁辅修职业或增加共鸣槽。

普通与极限通关均暂不产出典籍或残页，获取方式留待后续设计。保留已收藏典籍、已有残页及旧版待领奖励；二阶消耗3残页＋200金币，三阶6残页＋600金币。

导师、遗物、额外合成配方本轮暂不实现。

## 三十件物品与背包

每职业十件：一格无分支一件，二／三／四格各含两种攻击系列和一种功能系列。九种五格定义保留但不投放。固定朝向，含直线、各向L形和功能四格方形；无T形、不旋转。正式接入像素样稿v9与盗贼剑类拼图修订，3／4格均双剑；4格L均为2×3竖向，敌人朝左。

- 常规合成最高四阶，同名同阶拖动合并，形象／占格不变。颜色基础白绿／蓝／紫／金，四阶人物属性倍率1／1.5／2／3。
- 攻击、生命、防御全部加给人物；每件物品具有自身的回合技能，读取最终人物属性。毒、灼烧、破甲、标记、护盾和有限治疗来自物品本身，无需先选共鸣。关内耐力／法力和资源消耗已取消。
- 一格物品给邻居增幅；三／四格部分物品接受指定邻居增幅。一个邻居接触多格只计算一次，外给最多两件一格来源，接受最多三件邻居。详情展示四阶属性、技能、联动方向与贡献标签。
- 详情布局采用阶位标题、装备状态、标签／共鸣值及人物属性，然后展示当前效果、相邻效果、升阶效果。相邻关系写明“谁→谁、增加哪项、每件百分比、数量上限”；人物攻击／最大生命／防御直接写全，不用A/H/D缩写。单格增幅限同职业目标。
- 初始15格，按各关战斗进度成片开放，常规路线最后一场战斗达到7×6共42格。开放格亮色、关闭格斜纹，新增格短亮。放不下需要玩家取舍。
- 点击装备只查看详情。拖动到空格移动；同名同级装备合并，上方掉落区也可合并。覆盖装备可互换则互换，否则移到上方；L形空白不算占用。
- 两轮起始装备、每场战后三件均全部提供，允许重复，并提高当前构筑的合成材料权重。未入包装备在下一小节点自动转1点；不等大阶段。起始配置可整理两轮，出发前统一回收未入包物品。
- 装备拖到左下重铸按钮主动转点，格子优先判定；6点后手动重铸一件随机物品。最后一件武器不能弃用。右下1×／2×／4×，暂停与单步在战斗工具中。
- 上方物品与包内物品同一格子尺寸，连续轮廓。历程与背包自动切换；历程左下可主动查看背包，完整历程保留且每节点只一个标记。装备与战斗出现时自动显示背包。
- 上方掉落区可完整显示四格直线，共鸣栏压缩、背包稍下移且尺寸不变。人物／敌人职业用剑、法杖、匕首图标；继续按钮按补给、探险、历程、共鸣、毕业状态变色。四阶物品用彩色外轮廓、底色与阶位角标共同区分。

## 共鸣与战斗

共48张候选共鸣：三职业各三条职业路线，共27张；七公共物品类别各一条路线，共21张。每条路线有低／进／高阶三个不同名称，公共剑跨战士和盗贼，公共辅助跨魔法书和炼金工具。初始＋三次试炼共选4次，每次3选1；初始只有低阶，选低阶后解锁同系进阶与高阶，高阶可直接出现。后续至少提供一个合法已选系的进／高阶候选（存在时）。名称阶位用蓝／紫／金区分，贡献激活三段另用刻度。

| 共鸣 | 三段门槛   | 贡献来源                       |
| ---- | ---------- | ------------------------------ |
| 职业 | 12／48／96 | 已入包本职业所有物品，包括一格 |
| 物品 | 4／12／24  | 已入包指定类别；一格无武器类别 |

贡献为占格×1／2／4／8，合并守恒。战士重击／连击／守势共享“战士”贡献，各物品还能给剑／枪／防御共鸣贡献。共鸣独立释放自己的技能、读取共享状态，不改写物品技能、伤害系数或冷却。

双方每轮各一次行动，速度决定先后，同速勇者先手；当轮顺序冻结、下一轮重算。2／3／4格攻击物品首次在第1／2／3回合发动，防护物品首次第1回合（含治疗的仍按占格延迟），之后按原冷却周期。功能物品 → 攻击物品 → 典籍 → 槽位顺序的共鸣。状态在受影响者行动开始结算；死亡停止动作。生命跨战斗保留，没有整理期间自动回血。

- 物理减伤60/(60＋防御)，法术60/(60＋0.7×防御)，真实伤害绕过防御但先消耗护盾。护盾上限50%生命；每个有限治疗来源单独最多3次，满血保留次数和纯治疗就绪。
- 战士克盗贼、盗贼克法师、法师克战士。双方有利伤害×1.15、逆向×0.90、同职业×1；真实伤害、治疗和护盾不受克制。敌人职业只是克制标签，不生成职业装备或共鸣。
- 六种小怪、五种Boss。三次守关和额外挑战均使用Boss模板，无独立精英档。Boss有重击、吐息、孵化等下一行动预告。蛛后幼蛛为独立HP／状态目标，最多同时2只、累计3只，下一次蛛后行动才攻击。
- 完成15轮后第16轮狂暴，16／18／20／22轮敌方增伤20／40／60／80%，封顶。暂停、倍速、跳过和读档不改变次数。
- 新遭遇用当前构筑六回合中性输出与生存预算估算实力，只部分跟随；生命不参与匹配，保留本局85%峰值保护。数值在历程开始前冻结，调整背包和重载不重抽。前三场新手怪种固定骷髅／史莱姆／幽魂，其后职业加权均衡并避免连三场同职业。
- 战力由成长、构筑、表现计算。v15评级C500／B1800／A3500／S6500，旧毕业评级保留原标准。毕业背包与共鸣专属于本人，不能转给其他勇者。
- 试炼胜利显示原境界→新境界及实际成长／治疗；每次只升一小阶。点击“完成培养”直接保存当前背包并结算，不再额外确认。结算首屏人物在左、境界在右，下方依次显示战力评级、四共鸣、属性、记录与金币奖励，固定网格布局适配一屏。
