# 人物分层绘制与拼接规范 v1

2026-10-19。适用于三职业随机人物及后续换图。本规范覆盖v21、v23初版中仅按水平线裁切、头部盖在领口上的做法。

## 完整人体基准

优先查素材库。新衣物按同一完整人体基准绘制完整人物，再等比处理整个身体，按部件语义拆分。禁止分别拉伸上衣或裤腿来拼身高。

统一透明画布128×192，领口约y43、腰线约y78、脚底y182。这些是定位锚点，不是裁切边界。站姿、朝向、比例、肩宽和颈部位置保持一致；任何部件都不按自身包围盒重新居中。完整原图、请求、基准、遮罩和修复前资源必须保存。

## 部件归属与层级

固定顺序：**后发 → 衣服后层 → 下装 → 头颈 → 衣服前层 → 前发**。

| 部件 | 包含 | 禁止残留 |
| --- | --- | --- |
| 头颈 | 单一头部、耳朵、脸、下巴、与该头肤色匹配的脖子 | 另一张脸、衣领、上衣 |
| 前／后发 | 发丝、发饰 | 耳朵、皮肤、脸轮廓、下巴黑线、脖子 |
| 衣服前层 | 衣领、上衣、衣带、袖子、手臂／手、前衣摆 | 原模特头或脖子、原裤子 |
| 衣服后层 | 该上衣的后摆、披风或后方附件 | 原裤子、其他上衣后摆 |
| 下装 | 裤子、裤腿、该下装靴子 | 上衣、前／后衣摆、袖子、手臂／手 |

衣服前后层绑定同一个`torso` ID，不独立随机。没有后摆时保留空透明后层。随机换裤子不能换掉上衣后摆。

脖子归头部所有，并向衣领后搭接。衣物原图的裸露颈部要清掉；衣领盖住脖子，V领只露出同一个头颈层的皮肤。禁止把脖子叠在衣领、链甲或胸甲上方。

头身定位必须比对下颌底、颈根、衣领中心和肩线，不能只看统一画布与脚底。头与头发一起移动，不能单独拉长脖子补位置差。本批头像下颌比完整人体原图高约3px，因此二者同步下移3px；换图须重新量定，不能把3px当通用偏移。

**禁止用纯色多边形延长脖子。** 保留原头像的下颌、耳后及颈根阴影，保证这些斜向明暗线连续；领口露出的下颈／胸口须使用同头像的肤色与明暗变化。延长区域渐进衔接，不出现单色长柱、直角台阶、横向断线或前后肤色突变。

## 遮罩处理

- 逐件识别衣领、前后摆、裤腰和手臂；不能以某个y值或固定左右边界证明部件归属。
- 水平裁切容易把低垂衣摆或上半截裤子带入错误部件。像素连通段只能辅助判断，细小手指也会产生独立连通段，必须核对源图。
- 领口使用逐套确认的开口遮罩。肤色判断只能在该开口内辅助使用；不能按暖色整体抠除，避免误删金边和棕色胸甲。
- 发型中的假耳、下巴线和颈部按位置清除；不能全局删除浅金色，避免损坏金发。前后发透明图都要单独检查。
- 被衣物遮住的裤腰可用该下装自身的裤子像素补齐；不得复制包含上衣或手臂的行。短上衣混搭时仍要连贯、不露底色缝隙。
- 长袍从领口至袍摆保留在同一衣物前层，不在腰部切成两件。裤腿在后，真实开衩和袍摆下可以露出裤子／靴子，下装不能带第二件袍裙。
- 当前遮罩登记在`scripts/prepare-character-baseline.py`，领口遮罩另写入正式`manifest.json`。换源图后必须重新标定，禁止直接沿用旧坐标。

## 必须执行的验收

1. 单独查看透明部件，确认归属；合成在深底、浅底及游戏使用的镜像方向查看。
2. 每性别全部头×全部发型×各衣领交叉检查；每职业全部衣物×全部下装交叉检查。查看原尺寸和最近邻放大图，重点检查耳后、下巴、领口、腰侧、手指和后摆。
3. 固定回归用户截图中的组合：女头1／发5／盗贼衣1／裤3，女头3／发7／盗贼衣3／裤1（均为0起始ID）。不得只验收同套衣裤。
4. 自动检查尺寸、透明度、透明像素RGB、画布边界和接缝禁入区域。**边界通过不等于拼接正确**，仍需目视接缝和部件归属。颈部有连续不透明像素也不能证明自然；必须对照原头像检查下颌阴影，并在领口近景检查长度、宽度和明暗过渡。
5. 接入正式资源后，在真实浏览器查看加点、典籍选择、装备背景探索、战斗、结算和档案。刷新核对外观一致；不得清空玩家存档来解决拼接问题。
6. 更新素材索引，登记来源／分类，再跑相应测试和构建。保留修复前后对照和检查结果。

当前正式60层：8头颈、8前发、8后发、12前衣物、12后衣物、12下装。`manifest.version=4`记录美术规范；`HeroAppearance.version=1`及已存四个随机部件ID不变。运行时只读正式素材，不依赖历史样稿目录。旧勇者没有分层ID时保留原整图。

## 颈部二次修正：上一轮的漏检

用户再次指出脖子像插入领口的长色块。上一轮虽然清除了发型中的重复轮廓，但将自然颈部截断后用单色多边形延长，破坏了下颌阴影；下巴还比完整人体源图高约3px。此前的尺寸／透明度／浏览器检查没有发现这个美术问题，不能用测试通过证明接缝自然。

本次保留原头像的下颌及颈根像素，头和全部发型同步下移3px，消除人为拉长；深V领露出的下颈，复用完整人体的颈胸明暗并映射到对应头像肤色，通过6px过渡衔接颈根。衣物、后摆、裤靴、画布和存档ID不改。

已近景查看原问题两组与三职业男女的头／发／领口交叉图。新增自动回归核对895个原生下颌／颈根像素原样保留，防止再次单色覆盖，同时检查下颈存在明暗变化；这些检查仍不能替代近景目视。
