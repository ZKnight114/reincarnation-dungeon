# v16后续：随机事件、守关流程与生命成长

2026-10-19。状态：已接入 v16，沿用存档格式15。下文保留设计讨论，实际实现与首轮调校见[本轮实施与验收](v16-历程事件与战后恢复实施验收.md)。

## 1. 最大生命成长与显示

所有增加最大生命的成长选项，同步按上限变化比例调整剩余生命，保留原有生命百分比。适用于月泉、轮盘及其他生命成长选项，不作为一次独立治疗。

计算规则：新当前生命 = 旧当前生命 ×（新最大生命 / 旧最大生命），不超过新上限；使用实际最终上限比值，避免重复叠加成长层时比例不一致。计算精度沿用生命系统，显示时按现有规则取整；不能使已死亡勇者复活。

例如：50 / 100生命选择最大生命+10%，结果为55 / 110，而非50 / 110；80 / 100选择最大生命+15%，结果为92 / 115。固定数值增加上限的选项也按新旧上限比同步。

所有游戏内提示只写“最大生命＋数值／百分比”，删除“不恢复当前生命”等附加说明。比例同步规则在内部规范与测试中解释，不给每个选项附加冗长提示；同步增长不计为治疗触发、吸血或治疗贡献。

## 2. 三次守关流程

每次正常阶段守关Boss前一个节点固定为月泉营地，供玩家选择恢复生命或提高最大生命。

建议沿用的月泉数值：恢复最大生命35%，或最大生命+12%。后者同步剩余生命比例。成长选项不因旧版三层体魄祝福上限失去可选性。

完整顺序：

1. 月泉遭遇历程 → 月泉二选一 → 结果历程。
2. 守关Boss遭遇历程 → 试炼难度选择（若需） → 战斗。
3. 获胜后立即恢复最大生命30%，在战斗结果历程中显示实际恢复量；提供本次战利品，玩家整理背包。
4. 下一节点进入遗物宝箱：遭遇历程 → 消耗10%生命获得3件装备，或跳过 → 结果历程与装备整理。
5. 随后进入晋升事件：遭遇历程 → 晋升演出与境界／属性成长 → 结果历程。晋升不重复发放Boss30%回血，撤销此前25%／35%／45%的独立晋阶治疗；生命成长选项的比例同步与实际治疗分开处理。
6. 晋升结束点击继续，进入下一节点，再选择共鸣。共鸣完成后继续后续旅程。

Boss恢复按胜利时、晋升前的最大生命计算，且只结算一次；不延迟到晋升或宝箱之后。失败不恢复。Boss战利品与宝箱装备均沿用下一小节点回收未入包物品的规则，进入下一节点前由玩家完成取舍。

遗物宝箱不再作为无代价普通赠物事件。用户已明确：消耗支付时当前生命10%，不是最大生命10%。内部保留比例计算精度，不向上取整把低生命勇者扣死；可以跳过。支付和奖励各执行一次。

路线已定：前三关常规18／24／28节点，第4–10关32节点；替换／重排现有节点，不增长总长度。开局、三个守关、三次晋升、四个共鸣、结业／可选极限等核心流程保留。完整位置见[补给数值与节点排布定稿](v16-补给数值与节点排布定稿.md)。

## 3. 额外极限Boss的例外

额外极限Boss按普通打怪流程推进：遭遇历程 → 战斗 → 胜利结果与装备 → 整理 → 继续。

不配置固定前置月泉，不配置后置遗物宝箱，不增加晋升或共鸣次数；获胜后恢复最大生命30%，在历程结果中展示。不同于普通怪10%的恢复，两者不叠加。

## 4. 旅人补给的大吉随机性

旅人补给保留3件全给。达到当前关卡／阶段要求的战力后，有概率转出大吉，获得更好的装备；未达要求只能获得低档装备。

表现流程：遭遇历程 → 好运揭晓操作／演出 → 平常或大吉结果历程 → 实际形状装备与背包整理。大吉作为这类补给的结果表现，不与命运六格属性轮盘混为一套奖励。

用户已授权确定数值，以下为首轮定稿，尚待接入后的实际平衡验证：

- 按关内显示的当前培养战力判定，未入包装备不计入。三阶段门槛依次为500+70×(关卡−1)、1400+140×(关卡−1)、2400+210×(关卡−1)，阶段按已晋升0／1／2次区分。
- 未达标大吉0%；达标大吉30%；达到门槛1.5倍大吉45%，封顶。各阶段低档／常规／大吉的三件阶位固定，详见[定稿档位表](v16-补给数值与节点排布定稿.md)。不直接产出四阶金装备。
- 基础档随阶段成长，低档不等于全程一阶；大吉至少一件比该阶段常规档更高一阶。
- 判定及奖励生成后保存，刷新不重新开奖；每次只有一份补给。

已确定自动揭晓：遭遇历程后播放约0.8秒好运演出，展示结果历程与装备，停在整理。没有额外“接受”确认弹板，后续仍由玩家手动继续。

## 5. 命运事件统一六格轮盘

命运轮盘、鲜血祭坛采用同一玩法，仅遭遇文案与标题不同，可以增加符文石碑、流浪占卜师等叙事变体。

规则：消耗支付时当前生命15%获得一次转盘机会，或选择离开。用户已明确按当前生命计算，撤销最大生命代价建议；内部保留比例计算精度，避免取整扣死。

六个等面积格子，生命／攻击／防御各两格，**三种属性交替排列，不把同属性两格放在一起**。按示意图建议顺时针顺序：

| 顺序 | 属性收益 |
| --- | --- |
| 1 | 最大生命+10% |
| 2 | 攻击+15% |
| 3 | 防御+15% |
| 4 | 最大生命+15% |
| 5 | 攻击+10% |
| 6 | 防御+10% |

生命收益按本文件第1节同步剩余生命比例。轮盘只提供基础属性，不发装备、点数或特殊效果，也不在转盘后追加基础祝福三选一。

保留建议：六格等概率，百分比在统一成长层内加算，不反复乘算造成膨胀。代价支付、开奖结果与领奖均需只执行一次；转动时禁止重开／连点，刷新保留同一次结果。

## 6. 所有事件的呈现顺序

统一为：**先播放遭遇历程文字 → 弹出选择弹板（若有） → 进行下一步事件操作（若有） → 结束后播放事件结果历程文字 → 玩家继续。**

- 选择弹板和实际操作可以分两步，例如先决定是否献祭，再进入转盘转动。
- 无选择的事件跳过选择弹板；无小游戏的事件跳过操作步骤，不为每个事件硬加确认。
- 结果历程包含代价、实际回血、属性成长、获得物品等；不能在操作前提前揭示未知结果。
- 遭遇与结果采用逐条文字／底框节奏，播放时继续按钮等待，播放完再变为可继续。
- 同一节点只显示一次节点提示，完整历程追加保留，旧内容超出视口后可翻看。
- 获得装备时先让结果记录可读，再进入装备／背包整理；结果继续保存在历程中。装备在前景、人物在背景探索的规则保留。
- 结果播完后由玩家手动继续，不自动跨越到下一节点或提前回收未入包装备。
- 弹板、转盘、挖宝与晋升状态需可保存／恢复，刷新不重复扣血、成长、回血或发装备。
