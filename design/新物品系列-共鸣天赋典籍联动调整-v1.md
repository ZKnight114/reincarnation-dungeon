公共类别为剑、枪、法杖、法球、弩、防御、辅助，共7类，不按职业重复建立。战士重击／连击／守势都读取同一战士职业贡献，法师与盗贼同理；物品仍同时提供所属职业和对应公共类别的贡献。

一格仅贡献职业，不贡献物品类别。双剑整体是一件物品，不能翻倍计算占格、贡献或触发次数。装备·魔法书属于辅助物品；外围修习典籍不占格、不提供共鸣贡献。

## 2. 共鸣调整

保留每职业三条职业路线，每条低／进／高阶三个不同共鸣。公共物品共鸣按七类各一条三阶路线重整，目标总池为职业27个＋物品21个＝48个，替代旧54个。新名称与完整效果表后续逐项设计，不直接将旧表自动套入新版。

| 原类别或路线 | 调整要求 |
| --- | --- |
| 战士剑＋盗贼匕首 | 合并为公共剑路线，共同贡献。基础效果兼顾两种构筑；毒刃与重击特色放在各自职业路线，不能要求有毒或护盾才提供基础价值。 |
| 枪／法杖 | 保留类别，核对新物品的破防、多段和灼烧配合。 |
| 原攻击型魔导书 | 冰霜攻击路线迁至法球；名称、说明与匹配对象同时更新。辅助魔法书不再承担原冰霜攻击映射。 |
| 弓弩 | 统一弩类，只匹配手弩；保留标记与连射配合，移除弓形制文案。 |
| 盾 | 扩为防御类，护臂／肩甲／盾均可贡献，不依赖具体装备部位。 |
| 原法袍／皮甲 | 重整为公共辅助路线，魔法书与炼金工具均可贡献，不能只对书、烟雾或旧皮甲治疗生效。 |

辅助共鸣应有通用基础价值，并可响应辅助物品原生回合技能的实际发动；新触发强度及每回合上限待设计，避免多件发动产生递归。防御共鸣读取实际护盾／受击等战斗事件，不因图片画了盾就假定物品会生盾。

暗影职业路线需按新生存来源检查，与炼金工具的单一主要效果配合；烟雾减伤仍为设计方向，不将未定稿数值视为已确认。移除皮甲后不能遗留“必须有皮甲”条件。

现有规则保留：职业门槛12／48／96、物品4／12／24，贡献占格×1／2／4／8；初始＋三次试炼共四次三选一；初始仅低阶，进／高阶需已选同路线低阶且允许直接选高阶。名称阶位与贡献三阶段独立，共鸣不改写物品技能、冷却或相邻联动。

候选池同步审核：职业共鸣仍来自主职业，公共物品共鸣按新类别供给；本职业三个类别正常可选，跨职业典籍带来的已入包装备类别需能参与对应公共路线。跨职业类别开放与权重待实施设计，不因开放物品类别额外提供其他职业的职业共鸣。

## 3. 天赋调整

保留恰好一条对应主职业的职业天赋，保底一条随机物品天赋、一条基础天赋，第四条从基础／物品抽取；蓝／紫／金，同名不同品质可共存，辅修不新增职业天赋。

| 原物品天赋 | 新天赋组与对象 |
| --- | --- |
| 剑术＋匕首专长 | 合并为剑术专长，覆盖战士剑和盗贼短剑／双剑，不保留两套叠加副本。 |
| 枪术／法杖专长 | 保留，匹配对应新系列。 |
| 原魔导书专长 | 改为法球专长，冰霜攻击与减速配合对象迁至法球。 |
| 弓弩专长 | 改为弩术专长，匹配所有手弩。 |
| 盾牌专长 | 改为防御专长，覆盖护臂／肩甲／盾的已有原生防护效果。 |
| 法袍＋皮甲专长 | 重整为辅助专长，覆盖魔法书和炼金工具已有主要效果；旧皮甲治疗增幅不能直接留给没有治疗技能的烟雾瓶。 |

公共物品天赋按类别匹配，取消仅用“职业＋分支”限制；随机物品池仍允许与主职业不匹配的类别，支持辅修。规模目标为4基础＋3职业＋7物品＝14组、42品质版本，覆盖旧16组／48版本草案。旧JSON保留，新JSON与逐项数值表一起更新。

天赋直接增幅匹配物品的原生效果，不放大共鸣／典籍技能，不赋予物品本来没有的技能。辅助技能强度、持续、冷却是不同字段，不能用“辅助效果增强”同时放大三者；每档具体增幅及上限待逐项定稿。

## 4. 九本典籍调整

数量仍为每职业三本、共九本；保留外围收集升阶、人物属性增幅、一个回合自动技能，加点后选择且不限制主职业。第一节是新的系列对应表，具体改写如下：

- 裂岩剑典／穿阵枪谱／焚星秘典：保留主要构筑方向，更新新系列名单。
- 堡垒战法：对应整个防具系列，不限盾形物品；技能读取实际护盾，检查新物品能否建立对应条件。
- 霜界魔典：对应法球，原攻击型书的掉落、说明、组合示例迁至法球。
- 星幕仪典：对应辅助魔法书，重整结界与奥术配合，移除法袍投放和匹配。
- 蚀影刃典：对应盗贼短剑／双剑，保留毒刃特色；公共剑类别不会赋予战士剑毒刃原生技能。
- 追猎弩典：对应手弩，移除弓掉落及文案，保留标记与连射。
- 夜行秘卷：对应炼金工具，按新生存效果重整；移除皮甲投放和条件。若保留独立治疗，属于典籍自身技能，不能复制成炼金工具技能。

典籍关联投放按“典籍所属职业＋具体系列”，不能只按公共类别：裂岩剑典关联战士剑，蚀影刃典关联盗贼剑；星幕仪典关联法师魔法书，夜行秘卷关联盗贼炼金工具。战士选择夜行秘卷时可小概率获得盗贼炼金工具，不自动混入法师魔法书。典籍不改变勇者主职业或克制标签。

旧属性增幅及冷却数值仅作参考，不因美术替换自动改变；涉及新主要效果的技能重写后验证平衡。典籍产出方案仍留后续，过关不重新开放残页奖励。

## 5. 同步实施范围

一起更新30件物品原生技能与相邻联动、类别贡献、公共共鸣前置与候选、天赋随机与匹配、典籍技能／跨职业掉落、人物战力评估、详情文案、毕业装备及存档标识。导师／遗物／特殊合成配方继续暂缓。

验收重点：战士与盗贼剑对同一公共天赋／共鸣有效；魔法书与炼金工具均能贡献辅助；一格不提供类别贡献；双剑不翻倍；跨职业典籍投放正确系列且能参与公共类别；四次共鸣、四条天赋与九本典籍数量保持；原生技能与共鸣／典籍效果分别归因；新配置无旧匕首／弓／法袍／皮甲的失效条件。
