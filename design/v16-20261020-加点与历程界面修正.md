# v16 加点、典籍与事件界面修正

2026-10-20，已实施用户最新11项问题及“典籍说明精简、不增加滑动区”的补充要求。

| 项目 | 本次处理 |
| --- | --- |
| 资质 | 图标与平凡／出众／卓越／传奇名称并列；移除详情入口及保底描述，生成规则不变。 |
| 加点加减 | 34px简单细边按钮，只显示加减符号，保留禁用和按下反馈。 |
| 加点确认 | 文字统一为“确认加点”，居中210px宽；剩余点数继续显示在属性点区域。 |
| 典籍选择 | 详情184px降为138px，取消内部滚动；保留选中直接预览。九本说明统一为属性、发动周期、主要技能与联动，技能数值从实际战斗定义读取；点击书本仍可看完整规则。 |
| 历程出现 | 第一条公会启程也播放动效。事件新文字、背包切回后新文字继续排队；旧记录不重新播放。先更新历程队列，再判断事件弹板是否可开。 |
| 旅人补给 | 揭晓过程不打开临时弹板。揭晓与历程结束后只打开一次带标题、说明和确认的正式弹板；填好内容后才打开，避免上一事件内容瞬间出现。概率、档位与存档中的既定结果不变。 |
| 装备选中 | 移除SVG外接矩形的焦点外框、阴影和位移，仅描黄实际占格路径；键盘焦点也使用该路径。 |
| 月泉营地 | 两项抉择上方显示当前生命／最大生命及真实百分比血条。 |
| 刺客职业 | 当前职业名、天赋、共鸣、典籍、贡献标签、敌人及远征说明改“刺客”，单字职业牌改“刺”；内部rogue、物品／典籍／共鸣ID保持稳定，旧存档历程不追溯改写。 |
| 共鸣栏 | 移除为旧图标预留的左17px空位，文字在槽位内居中。 |
| 挖宝结果 | 挖出装备时仍即时入库并显示挖出效果，结果历程只在结束时记录一条“挖宝结束：挖出x件装备”。 |
