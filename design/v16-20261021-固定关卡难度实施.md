# v16：固定关卡难度实施

日期：2026-10-21。用户明确：此前“怪物跟随成长”是指固定数值下，怪物随关卡推进逐渐变强，而不是追踪本局玩家构筑。当前实现已按这一解释修改，继续使用v16；未提交、推送或部署。

本记录替代 `v16-20261021-护盾与数值机制复查.md` 和此前实施记录中的敌人自适应部分。护盾收紧、职业天赋修正、典籍／共鸣分工、第10回合狂暴等继续生效。

## 当前规则

- 第1–10关各有固定生命／攻击曲线。关内使用节点位置计算进度，越往后基准越高；再乘固定物种系数、守关阶段倍率与玩家主动选择的Boss难度档。
- **同一关、同一节点、同一种怪物、同一难度档，数值一致**。普通怪种类仍按原有随机池选择，Boss种类仍按关卡和阶段排定；随机选择物种不会随机浮动该物种的属性。
- 不读取玩家战力、主职业、当前／最大生命、防御、护盾、装备、相邻联动、天赋、共鸣、典籍、公会投入或本局历史峰值。爆发典籍和持久典籍不再生成不同生命的敌人。
- 成熟构筑可以更快击杀、更少掉血；较弱构筑可以失败。公会、资质和装备的提升完整作用于玩家，不再额外补强怪物。
- 遭遇种类在历程开始时确定并保存；选择Boss档位时使用同一份固定基准加倍率。战斗中不重新生成，刷新或读档不重抽。
- 前三关仍保留现有短路线、三次守关和四次共鸣选择；路线长度和事件顺序未重排。
- 远征原本就采用固定关卡数值，继续复用同一个战斗引擎，不改变远征章节的数值表。

实现：`src/enemies.ts`读取 `src/enemy-catalogue.json` 的 `fixedGrowth.chapters`；`src/game.ts`不再把战力传给生成器、不再更新用于跟随敌人的历史峰值。删除已无调用的敌人压力估算和构筑跟随系数。毕业评分及补给战力门槛仍使用自己的构筑评分，不受删除影响。

生命／攻击＝基础项＋一次项×p＋二次项×p²，p＝min（1，当前节点索引／（正常路线长度－1））。下表为不含物种和Boss倍率的参考端点；100%通常是结业位置，实际最后一场普通战按其实际节点计算。

防御＝（4＋6p＋2.2×（关卡－1））×物种系数；速度＝round（（10＋floor（3p）＋floor（（关卡－1）／3））×物种系数），至少1。生命取整，基础攻击保留两位小数。

### 守关与极限Boss

| 位置 | 生命倍率 | 攻击倍率 |
| --- | ---: | ---: |
| 第一次守关 | 1.30 | 1.10 |
| 第二次守关 | 1.35 | 1.65 |
| 第三次守关 | 1.45 | 2.00 |
| 首次极限Boss | 1.55 | 2.10 |

守关倍率作用于该节点的普通基准，不是各场Boss用同一份生命值。节点基准随阶段增加，因此倍率小幅递增仍有明显的生命与攻击递进。

三档主动试炼继续额外乘：守望生命／攻击1／1，勇气1.2／1.12，英雄1.45／1.28。使用 `TRIALS` 中同一份定义，不在生成器重复套档位倍率。

极限Boss使用正常路线100%进度基准，之后每场生命倍率＋0.12，攻击倍率＋0.16；保留各Boss技能、职业克制、低血阶段和狂暴。

初次固定配置抽样曾出现后期Boss生命偏高，爆发流超过12回合。已通过固定阶段倍率减小入口生命门槛、收紧守关生命量；调整仍是所有玩家共用的配置，不因某次构筑强弱改变。

## 存档与交付

不清空当前combat3存档或备份，不改存档键。旧存档中的 `peakStrength` 字段仅为格式兼容保留，不再参与敌人生成；已生成的旧遭遇和正在播放的远征战报保留历史结果。下一次新遭遇采用固定规则。
