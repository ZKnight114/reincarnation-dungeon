## 已发现并修正

| 问题 | 原因与修正 |
| --- | --- |
| 周期护盾累积过快，敌人难以造成实际生命损失 | 勇者的物品／典籍周期护盾技能降低35%；护盾储量上限从50%最大生命降到30%。开局盾、低血救援和小额条件被动盾保留原系数，均受新储量上限约束。敌人护盾不随勇者一起削弱。 |
| 削护盾后，怪物攻击也下降，抵消调整 | 过去敌人伤害预算过度跟随治疗／护盾产量。改为主要参考非公会最大生命、防御，小比例参考保护产量。购买公会增益不会等量推高怪物，当前残血也不影响怪物生成。 |
| 前三关敌人对构筑的伤害跟随量为零，容易一直无损 | 第一至第四关的攻击跟随比例依次为25%／30%／35%／45%，后续55%。仍保留前期教学减压和较低生命跟随比例。 |
| 首次Boss压力突增，后续反而容易被成熟构筑压住 | 三次守关的最大生命压力系数依次10%／14%／16%，极限Boss16%，让压力按阶段递增。不是把所有Boss套同一个高系数。 |
| 新共鸣伤害和共鸣护盾漏算对应职业天赋 | 伤害统一按来源处理职业增幅；共鸣追击可获得对应职业增幅，但不获得物品原生伤害天赋。被动护盾补上来源的护盾增幅。原生持续伤害／反击此前已保存职业增幅，结算不再次叠加。天赋反伤仍不额外放大。 |
| 职业增幅补齐后，持续伤害上限可能失效 | 先计算各来源有效强度，再统一限制每种毒／灼烧总强度为攻击的40%，最后逐来源结算。技能读取持续伤害和状态详情复用相同强度口径；不改写已存储状态值。 |

实现集中在 `src/combat-balance.ts`、`src/combat.ts`、`src/combat-rules.ts` 与 `src/enemies.ts`。物品、典籍和状态说明同步更新。

### 护盾执行口径

- 周期护盾指勇者技能动作中有冷却的护盾动作，执行乘0.65；触发型救援的动作、开局盾、小额共鸣响应与典籍施放后条件奖励不一并削弱。
- 守卫塔盾四阶主盾：14%生命＋160%防御 → **9.1%生命＋104%防御**；低血救援6%生命保留。
- 堡垒战法、星幕仪典、夜行秘卷主盾：5%／7%／9%生命 → **3.25%／4.55%／5.85%生命**。
- 霜界魔典、蚀影刃典技能动作中的条件盾：10%攻击 → **6.5%攻击**。裂岩剑典、穿阵枪谱、追猎弩典施放后的条件奖励盾10%攻击保留。
- 同时叠加多个来源也不能突破30%最大生命储量；达到上限后的无效加盾不应算有效辅助收益。

### 敌人生成口径

每次生成新遭遇时，先估算中性环境下构筑12回合的输出和保护产量；已生成敌人冻结，不跟随战中换装或残血变化。

压力攻击＝非公会最大生命×生命压力系数＋非公会防御×防御系数＋保护产量×15%。普通怪生命压力10%、防御系数20%；三次Boss生命压力10%／14%／16%、防御系数30%；极限Boss生命压力16%。

混合攻击＝基础攻击×（1－跟随比例）＋max（基础攻击，压力攻击）×跟随比例；然后应用Boss阶段、物种、教学期和路线倍率。具体规则同时记录在 `src/enemy-catalogue.json`。

## 已复查、保留的机制边界

| 机制 | 当前结论 |
| --- | --- |
| 直接治疗次数 | 物品原生治疗按原有技能动作限次，默认每战3次；满血不消耗有效治疗次数。夜行秘卷的直接治疗由4回合冷却约束，不套3次限制。 |
| 回生Buff | 在随后两次勇者行动开始结算；同来源刷新，不叠多份、不立即多跳一次、不复活；满血照常消耗持续次数。 |
| 共鸣吸血 | 只按符合条件的实际生命伤害计算；不含护盾损耗、过量伤害、持续伤害或被动追击。各来源有上限，共鸣合计每回合最多2%最大生命。天赋吸血沿用独立的原有预算，未偷偷合并成一份。 |
| 烟幕与减伤 | 同类烟幕取最高；烟幕与直接减伤合计最多45%。毒／灼烧不读取只对直接攻击生效的减伤。 |
| 穿防 | 多来源合计最多70%；真实伤害按既有规则处理，不再重复计算职业克制。 |
| 毒／灼烧 | 各来源刷新持续，同类总强度在职业加成之后限制为攻击的40%；额外共鸣追击属于独立附加伤害，不冒充持续伤害。 |
| 追击、反击及星能 | 被动追击不会再次触发原生事件；反击不递归；星能附伤属于典籍原生命中，能参与符合条件的吸血。 |
| 生命上限事件 | 按用户设计，剩余生命随上限等比例改变；不改成固定当前生命，也不写成无恢复效果。 |
| 公会成长 | 敌人自适应主要使用非公会属性；不会把玩家花货币获得的提升完全抵消。 |

## 仍需继续精调的数值

上述都是程序合成与排包抽样，**不能解释为真实玩家胜率**。前期教学较宽松；后期弱构筑和投入不足有失败风险，但不能据此认定所有流派已平衡。

当前星幕仪典的成熟防御构筑仍有接近无损的样本；刺客遭遇不利职业／Boss模板时，第一场Boss仍可能损失超过60%最大生命。部分强爆发在5回合结束，裂岩等部分后期Boss又会到9回合。普通战15%–20%、Boss35%–50%的目标仍是中上构筑的参考范围，尚未在所有组合达成。

后续应优先对比星幕的护盾／减伤叠加，以及刺客对特定Boss的峰值伤害；逐流派、物种和投入档位精调，不继续无差别提高全部敌人攻击，也不靠反向抹掉公会收益来强行统一战损。
