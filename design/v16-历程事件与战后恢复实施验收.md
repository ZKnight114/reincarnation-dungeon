# v16：历程事件与战后恢复实施验收

2026-10-19。正式版本仍为 v16 / 16.0.0，存档格式与键仍为15。已实施本轮确认的9组调整，无新增绘图调用。

## 已接入内容

1. 选择典籍后先播放公会启程历程，再提供两轮各3件随机起始装备；初始共鸣后播放整备完成历程，随后开始正式路线。

2. 遭遇前冲采用后倾准备、俯冲、减速和收势，动画完成后进入战斗。战斗加入职业待机；动作只影响人物身体层，血条、影子锚点及装备拖动区域保持固定，攻击与受击期间退出待机。

3. 普通怪胜利按当时最大生命恢复10%，守关和额外Boss恢复30%，生命封顶。恢复立即记录在胜利历程中，不计入物品治疗贡献，不触发治疗联动；失败不复活。晋升取消旧25%／35%／45%额外治疗。战斗报告单独记录恢复前生命与实际恢复量。

4. 月泉、轮盘、固定最大生命成长与晋升属性成长都按新旧最大生命比例同步剩余生命。月泉成长最大生命＋12%，显示不附加“不会恢复当前生命”等提示。装备更换本身不视为生命成长事件。

5. 三次正常守关严格采用月泉 → Boss → 战后恢复及三件装备 → 血封宝箱 → 独立晋升 → 下一节点先选择共鸣、再执行该节点事件。晋升结束不多跳一步；额外Boss不配置月泉、宝箱、晋升或额外共鸣。

6. 宝箱消耗当前生命10%换3件装备，可放弃；轮盘消耗当前生命15%，六格等概率、按生命／攻击／防御交替排列，分别＋10%或＋15%。支付保留小数，微小代价显示“不足0.01”；仅生命不超过0才阻止支付。结果保存后才演出，领取一次后结束事件，不再发装备、点数或额外buff选择。

7. 旅人补给按入包构筑的当前显示战力判断固定关卡／阶段门槛，采用既定30%／45%大吉概率和三阶段档位。三件全部给出，允许重复模板，直接奖励最高紫色三阶。自动揭晓无接受按钮，未达门槛不会展示伪大吉滚动。

8. 所有事件先播放遭遇历程，再显示抉择或操作，结果文本播放后由玩家继续。装备奖励的结果文字先展示，随后自动切换背包与前景装备，人物继续位于背景层。未入包装备在下一小节点回收；不等待大阶段结束。完整历史保留，同一节点仍只有一个时间标记。

9. 前三关正常18／24／28步，第4–10关正常32步；仍是3次小阶晋升和4个共鸣。最后一次正常战斗后开放全部42格。不同阶段的补给数值、完整节点表见[定稿](v16-补给数值与节点排布定稿.md)。
