本规范记录像素样稿v9与盗贼剑类拼图试绘中确认的风格、精细度和制作方式。物品身份、占格与展示通则继续遵循 [物品美术展示规范v2](物品美术展示规范-v2.md) 和 [三职业物品安排v2](三职业物品安排-v2.md)。美术规范不自动改变技能、数值、贡献标签或玩法。

## 1. 风格与物品界定

统一采用**精细像素西幻装备图标**：清楚的阶梯像素轮廓、有限调色、明确的金属／木材／皮革／晶体材质，统一左上光照。主体自然、结构可信；避免写实3D、模糊渐变、大片光晕，以及缩小后变成噪点的装饰。

每张独立物品素材只包含这一件装备及其合理附件，不画人物、场景、标题、品质底板、格线或按钮。图集中的多个物品保持彼此独立。装备主体与附件算一个物品，例如双剑的两把剑、手弩与配套弩矢盒、魔法书与羽毛笔，不额外形成可领取物品或类别贡献。

每职业10件：一件1格基础物品，三系列各含2／3／4格。5格预留，不新增系列或为了画图增加物品数量。

| 职业 | 系列与视觉特征 |
| --- | --- |
| 战士 | 剑／枪／防具。剑偏宽刃、厚重、骑士风格，冷银钢与古铜护手、棕红握柄；枪保留自然直杆与清楚枪刃；防具允许护臂、肩甲、盾等不同部位。 |
| 法师 | 法杖／法球／辅助魔法书。法杖用暖色晶体与细长杆，法球用冰蓝球体与环轨，书用紫蓝书封与金铜扣饰；三个系列轮廓明显不同。 |
| 盗贼 | 短剑与双剑／手弩／炼金工具。剑用窄直刃、黑铁短护手、墨绿缠柄与月牙尾饰；3／4格均为两把完整短剑。手弩保留弩身、弩臂、弩弦及扳机，不画弓。炼金工具外观围绕统一主要效果，不堆入多种无关道具。 |

战士与盗贼共用剑类别，但必须通过**主体轮廓、护手、握柄与材质配色**区分职业，不能只改颜色或名称。各系列2／3／4格保持武器类别，功能系列可采用不同部位装备。同职业同系列同占格对应同一物品；同物品四阶保持身份、主体与占格，不把升阶画成另一件装备。

4格重点物品可增加刻纹、符文、宝石高光、缠带、铆钉和小挂件。装饰必须服务原主题、缩小后可读，保持主体完整；特效局限在装备附近，不扩出逻辑占格、不遮住旁边装备。战士重剑细化版是参考，不要求所有物品都堆满同样细节。

## 2. 固定占格与自然构图

- 不开放旋转、不使用T形；同职业混合直线和L形，同格数的L朝向尽量不同。
- 4格L统一为竖向2列×3行，不使用横向4格L；4格横／竖直线仍可用，只有功能系列4格可使用2×2。
- 使用最新固定占格定义。直剑、枪、杖等可自然斜放，也可搭配合理附件形成L形；不把武器弯成直角。
- 插画可以留白，不强求每格都有主体。连续底板与外轮廓由UI显示，负责说明实际占格。
- 剑尖、护手、握柄、杖头、弩臂及重要附件必须完整。主体无法放下时调整构图或等比缩放，禁止用占格蒙版裁掉主体。
- 物品升阶主要通过基础白绿色系／蓝／紫／金的底板、连续轮廓和角标区分；插画材质色用于表达装备身份。品质底板由UI生成，避免重复绘制四张仅颜色不同的装备图。

## 3. 精细度与尺寸

以**游戏实机尺寸的辨认效果**决定精细度，不以1024大图能否看见微小刻纹作为标准。当前背包与上方掉落采用50px单格，素材默认按64px单格保存，留出适度缩放余量；两处使用相同单格比例。

| 占格包围范围 | 默认透明PNG尺寸 |
| --- | --- |
| 1×1 | 64×64 |
| 1×2／2×1 | 64×128／128×64 |
| 1×3／3×1 | 64×192／192×64 |
| 3格L、4格2×2 | 128×128 |
| 4格竖L，2×3范围 | 128×192 |
| 1×4／4×1 | 64×256／256×64 |

尺寸表示透明画布与逻辑包围范围，不要求插画填满整个画布或L形缺口。等比缩放，不拉伸主体；像素素材缩放优先保持清楚像素边缘。

精细度优先顺序为：**主体轮廓 → 职业与系列区别 → 材质块面和主要高光 → 少量装饰细节**。50px单格下应能认出物品、判断单剑／双剑、区分职业，并读清占格和品质。小尺寸下看不清的细纹可以省略；过暗、过细或过多碎高光导致难辨时，优先强化主体块面。

不再默认每件单独生成1024×1024。常规小批图集可从512×512开始，确认每件分到的像素足够；复杂物品或更多件同图时按需要提高整张图集分辨率。生成精细度以medium作为当前起点，只有实机检查确实不足时再提高；未指定模型时保留服务默认选择。

## 4. 优先合并绘图，再拆分

**能合并绘图的就合并绘图后拆分。**优先将同职业、同系列、风格一致的物品放进一张图集，常规每张3件；适合的小件可扩到3–6件，不能因拼得太多而失去实机精细度。仅构图复杂、需要局部修正或图集无法保证完整主体的物品单独绘制／编辑。

制作流程：

1. 先列出物品身份、数量、固定占格、方向与完整构图，明确每件所占的图集区域。
2. 准备构图参考和风格参考，说明各自作用，保持物品之间足够空白；单剑／双剑的实际数量写清楚。
3. 一次生成整张图集，背景统一。当前可用纯洋红背景，拆分后去背景并清理边缘混色；物品本身避免使用同一抠图色。有可靠透明输出时可保留原生透明。
4. 按实际主体之间的空白切分，不机械按等分线裁图。若生成位置偏移，先寻找安全分隔；不能切断剑尖、护手或附件。
5. 分别整理成透明PNG，等比适配原占格，检查非透明像素是否越界、主体是否完整、物品是否串图或缺件。
6. 在实机50px单格、上方掉落和拥挤背包里检查；四阶使用同一插画验证，品质变化交给底板与轮廓。
7. 只有失败单件重新绘制／局部编辑，保留图集中已成功的物品；旧稿、原图、切图结果、提示词及实际积分记录均保存。

批量调用多个独立绘图请求不等于图集合并。本规则要求尽量在**一次生成的一张图**内完成多件，再本地拆分。

## 5. 积分依据与参考

已验证的盗贼剑试绘：一张512×512图切出3件，实际扣25基础积分；此前单件24–26积分，分别生成3件估算72–78积分，本次约省三分之二。单次扣费仍接近原单件，节省主要来自合并绘制，不能把输出尺寸减半解释成积分也减半。后续仍记录实际扣分，避免返工抵消节省。
