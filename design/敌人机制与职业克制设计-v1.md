# 敌人机制、狂暴与职业克制 · 首版设计

实施状态（2026-10-15）：已接入v15。下文保留首版讨论数值，最终实施差异和验证范围见 [v15实施与验收](v15实施与验收.md)。

日期：2026-10-15。状态：**设计方案，未修改游戏，数值未完成战斗平衡验证**。按用户最新修正：敌人职业只用于双方克制，不扩展实际职业配置；三次阶段守关和额外试炼都使用Boss模板；敌人随勇者当前实力成长。本方案复用现有立绘，设计11种敌人：6种小怪、5种Boss，不新增美术需求；其他已有定义暂不投放。旧版固定敌人数值与独立精英档的提案由本修订覆盖。

## 1. 双方共享规则，构筑来源不同

- 双方都有攻击A、生命／上限H、防御D、速度S、护盾、治疗、物理／法术／真实伤害、回合冷却、状态及行动归因；玩家的物品、典籍、共鸣与敌人的固定技能使用同一技能执行器和伤害／护盾／状态结算器。
- 玩家通过人物／物品／典籍／公会汇总属性，物品自动技能＋典籍技能＋独立共鸣形成组合。敌人通过章节／进度基准＋勇者实力成长修正＋怪种系数＋固定技能组形成组合，没有42格背包、物品合并、典籍收藏或共鸣选取流程。
- 敌人周期主技能默认**替代该次普通攻击**，不是普攻＋所有技能同时发动；固定辅助技能只在表中明确的行动触发。主要攻击次数不会因为速度快而多一回合，玩家也不因变慢失去回合。
- 伤害统一提案：物理raw×60/(60+D)，法术raw×60/(60+0.7D)，真实伤害不受D。旧玩家法术0.5防御系数和旧敌人全部物理计算由此统一替换；法术不再只是名字不同。系数0.7待平衡校准。
- 单次忽略防御和持续破防相乘，不相加到100%；真实伤害绕过防御，**仍先消耗护盾**，不会默认无视护盾。治疗不超过H，护盾统一上限50%H。
- 毒／灼烧／冰霜减速／破防／标记都可按合法技能施加到双方，记录施加者、原始量、剩余行动、来源ID。普通敌人不用全部状态，但引擎不能只支持敌人受状态。毒／灼烧原始量上限按每攻击阵营、每实际目标40%施加方当前攻击计算，沿用物品表，双方对称；同来源刷新，不复制出无限层。
- 总伤害公式为：原始技能量 → 破防／忽略防御后的相应防御减伤 → 非真实伤害的职业修正 → 来源敌人的狂暴／阶段修正 → 护盾吸收 → 实际生命扣除。伤害与实际生命／护盾分别归因；吸血只取实际生命伤害。技能多段每段应用一次，没有额外隐藏普攻。
- 一轮含双方各一次行动，速度决定先后，同速勇者先手，下一轮重算顺序。技能冷却按施法者自己的行动次数记录；预告用“下一次该敌人行动”表达，避免速度变化让文案错位。
- 周期普通技能在首次自身行动就绪，表中特殊第N次动作以明确计数为准。状态伤害在受影响者自己回合开始结算，死亡则不行动；伤害／治疗／护盾逐步检查结果，不在死亡后继续放技能。

## 2. 职业克制：双方对称，怪物显示战斗职业

### 克制关系

**战士克盗贼 → 盗贼克法师 → 法师克战士。** 怪物拥有可见的战斗职业标签：重甲／正面型归战士，敏捷／毒袭型归盗贼，法术／吐息型归法师。标签由怪种固定，不根据玩家职业或当前装备暗改。**职业仅参与克制判定**，不额外授予职业属性、职业技能、三系配置或职业被动；毒、吐息、护盾等能力来自怪种自己的固定技能。

| 攻击方\防守方 | 战士  | 法师  | 盗贼  |
| ------------- | ----- | ----- | ----- |
| 战士          | ×1.00 | ×0.90 | ×1.15 |
| 法师          | ×1.15 | ×1.00 | ×0.90 |
| 盗贼          | ×0.90 | ×1.15 | ×1.00 |

- 每次伤害只查这一张矩阵一次，不再额外叠“对方被克制减防”或“我被克制再减伤”。例如战士打盗贼＋15%，盗贼打战士－10%；敌人打玩家完全同一规则。
- 克制调整**物理与法术直接伤害、反击以及灼烧**，同一伤害只应用一次；真实伤害暂不受职业克制、也不吃防御，保留毒流的一条应对路径，但仍受技能上限与护盾约束。
- 毒／灼烧储存未乘克制的来源原始量，每次真正扣血时再计算。典籍／共鸣取“当前一次灼烧／毒值”也取原始量，随后仅在其独立伤害中应用一次矩阵，防止克制重复乘算。
- 不改变治疗、护盾、速度、状态持续时间或贡献点，不用克制直接改变技能倍率文字，也不额外增加抗性属性。
- 职业由勇者招募时确定，混搭本职业三系不改变职业。召唤物继承召唤者标签；未来无职业事件伤害使用×1.00，不能冒用战斗克制。
- 正式培养的怪种池保持职业多样，不根据玩家反向匹配、也不让整关全部克制玩家。第一关前三场暂固定骷髅／史莱姆／幽魂，技能依次介绍直接攻击、护盾、法术，不随勇者职业更换怪种。其后6种小怪池为战士2／盗贼3／法师1，每只权重分别1／2⁄3／2，使三职业总权重各2、长期各约1⁄3；关卡中可随机但避免连续3场同一敌方职业。不会保证每次有利怪种，Boss按固定章节配置，章节配置应覆盖三职业，不跟随玩家职业改变。
- 单场敌人职业在进入战斗前的遭遇描述／敌人名旁显示，可查看技能；玩家仍靠背包、合成、技能与共鸣取舍应对。不保证有利职业必胜，也不以无提示免疫禁用流派。

## 3. 超时狂暴：先选15，按完整回合计数

- 全部小怪／Boss统一采用**完成15轮后，第16轮开始进入狂暴**。不是第15次敌方行动、不是每次技能计为一轮，也不按现实秒数计算。
- 第14轮显示轻量预警，第16轮顶部敌人状态出现狂暴标记与一次历程／战斗日志，不重复弹窗打断战斗。
- 第16／18／20／22轮起敌方伤害倍率分别为**1.20／1.40／1.60／1.80**，1.80封顶。仅敌方伤害增长，不恢复血、不提高防御、不更换职业、不加速、不缩冷却、不多行动。第17／19／21轮分别维持前一档，不每回合另加20%。
- 倍率适用于敌方本体／幼蛛直接伤害和本敌人施加的毒／灼烧。状态存原始量，在结算时读取当前狂暴倍率一次；不能施加时乘一次、结算时再乘一次。
- 低血Boss阶段伤害加成与狂暴百分比相加后乘一次。例如白骨王第二阶段＋10%，第16轮狂暴＋20%，其伤害为原来×1.30，而非×1.10×1.20。单次技能伤害系数与防御／职业修正仍按公式顺序使用。
- 初始三关也按15轮，不为新手突然提前到10轮。极限挑战暂维持相同狂暴阈值，通过基础属性与技能提高压力；“10轮开始”保留为后续高难配置，不作为本次默认。
- 15轮结束前打赢不狂暴；第16轮开始统一生效，即使玩家先手，该轮受到敌方已有持续伤害也按狂暴计算。暂停、倍速、跳过展示、重载都不改变轮数或重复叠加倍率。
- 目标正常战斗时长：小怪3～6轮，第一阶段Boss6～8轮、第二阶段7～10轮、第三阶段8～12轮，额外试炼Boss10～14轮；这些是同一Boss模板的遭遇难度，不恢复精英类别。狂暴给偏防御构筑缓冲，但不能无限拖延。目标区间需按实际装备／共鸣／典籍验证，不是已验证结论。

## 4. 实力同步成长与Boss投放

### 4.1 生成时取快照，战斗中不追涨

- 点击继续进入下一遭遇时，读取勇者当前已入包装备、等级、相邻布局、人物最终A/H/D/S、已激活共鸣与本局绑定典籍；包含公会已经生效的属性增幅。上方未入包物品不算实力。
- 不直接按展示战力或境界定怪强度：相同战力的毒流、盾流和多段流，实际战斗能力可能不同。境界只展示培养进度，不额外附加隐形压制。
- 遭遇生成后保存敌人完整属性与快照版本；预告、弹窗、背包调整、开战、读档均复用该敌人，不重新取样。战斗内护盾、回血、状态变化和狂暴不重算成长系数。
- 当前剩余生命不参与成长。受伤不会使下一只怪变弱，低血也不会使怪额外变强；成长评估使用最大生命和构筑的完整技能能力。

### 4.2 部分跟随，保留构筑收益（首版数值建议）

- 用统一六回合中性基准评估构筑：O为六回合平均有效输出，包含物品、典籍、已激活共鸣、持续伤害、合理上限内的反击；E为六回合有效生存预算，包含最大生命、防御和可实际获得的有限护盾／治疗。使用同一组固定中性受击脚本，不使用即将遇到怪物的职业或技能来反向定制。
- 基准目标暂拟H=200／D=4／S=10，每行动造成12点原始物理伤害，没有职业克制。虚拟目标生命不足时仍保持可受击供技能评估；低血、击杀、反击等条件采用统一固定情景并汇总，不能通过无限低血执行或无限召唤高估输出。O/E的详细情景与权重须随统一战斗执行器实现后校准，目前未声称已有评估器。
- 综合实力B＝sqrt(O×E)。无伤害技能且O=0时，仅计算成长需要的O使用极小正数，不给玩家虚构攻击或放宽开战合法性检查。以本章当前进度的标准构筑B_ref作对照；标准构筑离线标定，不按玩家职业、剩余生命或敌人克制临时更换。
- 建议保留本局最高完整构筑实力B_peak，下次取B_eff=max(B_current,0.85×B_peak)。允许换装，但短暂卸装最多降低15%评估基准，不能卸光装备刷出极弱Boss。开局未完成六件提供和初始共鸣时不记峰值；之后只在玩家确认继续时更新并保存峰值，拖动中的临时布局不算。85%为待验证参数。
- 比值r=B_eff/B_ref。成长系数g=max(0.75,sqrt(r))，r≤2；r>2时g=sqrt(2)×(r/2)^0.25。高实力继续跟随但增幅更缓，不采用会停止成长的硬上限。章节基准保持最低挑战，怪物不完全复制玩家数值。
- 敌人生命乘g，攻击乘g^0.7；防御与速度按章节／进度和怪种设定，不与勇者逐项镜像。提升速度仍能争先手，穿防和职业克制的收益不被成长公式抵消。
- 例如同一章节／节点，构筑综合实力从标准值变为2倍，敌人生命约×1.41、攻击约×1.27；玩家强化仍有收益。超过2倍后跟随更缓。以上比较不包含切换节点本身带来的难度增加。

### 4.3 章节基准与模板难度

- 第一关开局普通怪参考基准H=200、A=12、D=4、S=10。标准进度p＝clamp[(当前1起算节点−1)/(本章常规结业节点−1),0,1]，章节c≥1。
- 基准H=200×(1+1.4p)×[1+0.10(c−1)]，A=12×(1+0.65p)×[1+0.06(c−1)]，D=4+4p+1.5(c−1)，S=10+floor(3p)+floor((c−1)/3)。节点使用实际短关／常规关长度；极限阶段p保持1。
- 最终H/A＝章节基准×成长系数（H用g、A用g^0.7）×遭遇难度×怪种系数×新手修正；D/S＝章节基准×怪种系数，取整和最低值在统一生成器中处理。技能表中的A/H/D始终读取最终敌人自身属性。
- 小怪遭遇难度H×1／A×1；三次阶段守关Boss暂拟H×2.8／3.4／4.0，A×1.10／1.18／1.25。额外试炼在当前阶段Boss难度上再乘H×1.25／A×1.15；不与旧精英或旧极限倍率重复叠加。
- 第一关H再×0.85、A×0.80；第二关H×0.95、A×0.90，第三关起标准值。若保留试炼可选难度，作为独立一次遭遇修正校准，不把“阶段序号”和“难度档”混为同一参数。
- Boss低血机制按各怪表执行；不是每个Boss必须有第二形态。成Boss体现完整技能、预告及守关挑战，不要求统一无提示增伤。

### 4.4 投放规则

- 只有小怪与Boss两类。魔像、巨魔、幼龙提升为Boss，与白骨王、蛛后组成5种Boss模板；三次阶段守关、额外试炼与极限守关都从Boss模板选择。
- 章节预设三个守关Boss与额外试炼候选，不依据勇者职业临时换怪；同一模板可在不同阶段出现，阶段难度由遭遇参数表达。小怪事件不混入隐形精英数值档。
- 额外试炼复用完整Boss技能，不只套更大的普通怪血条；仍按本次确认继续时的构筑生成并固定数值。召唤幼蛛属于Boss技能产物，不作为额外试炼的独立守关怪。
- 所有基准、B_ref标准构筑、评估情景、成长曲线与遭遇倍率均待联动物品／典籍／共鸣模拟，不把设计结构检查当作战斗平衡通过。

## 5. 11种敌人固定能力

## 6. 蛛后召唤统一规则

- 幼蛛拥有生命、防御、职业标签，但没有自己的独立行动队列，不把一轮变成玩家1次／敌方3次。单只生命5%蛛后H，攻击读取蛛后A；状态伤害不把幼蛛算作额外施法来源。
- 只在蛛后下一次自身行动开始时激活新幼蛛，当次孵化不额外攻击。每个已激活存活幼蛛在蛛后本体行动后追加30%A物理伤害；蛛后若因毒／灼烧在行动前死亡，幼蛛不继续攻击，战斗结束。
- 同时最多2只、每场最多召唤3只。孵化前已满2只则本次不新增、也不消耗总召唤次数；按下一次正常孵化再检查，不能偷偷堆满3只。狂暴同时作用幼蛛伤害，克制按盗贼标签执行一次。
- 玩家物品／典籍／共鸣的单体直接伤害优先打最早召唤的存活幼蛛，幼蛛死亡后下一段／下一技能自动转下一个，再回本体；单段过量伤害不溢出。攻击前状态条件读取当前实际目标，幼蛛不继承本体毒／标记等状态。
- 已施加在蛛后本体的毒／灼烧继续对本体结算，不因召唤转移。新的攻击造成状态则施加到该攻击的实际目标；幼蛛死亡清其自身状态。全体目标技能若将来投放，必须明确能击中幼蛛，不能把所有技能默认当AOE。
- 各目标分别维护状态，毒／灼烧40%A上限按来源阵营最终攻击、按每目标结算；召唤不复制现有状态、不重新算共鸣贡献。幼蛛的已有持续伤害在蛛后自身行动开始时与本体状态一起各自结算，受击状态时长按该次所属敌方行动扣减；死亡幼蛛本轮不能追加攻击。幼蛛不是额外回合，不能重复刷新狂暴或状态计数。
- 反击使用实际攻击者，幼蛛追加视为直接攻击，反击可直接命中触发它的幼蛛而非最早召唤者；各反击来源每敌方回合最多一次，不因为两只幼蛛追加再触发同一反击源。对本体反击也直接回击本体，不把伤害转给其他幼蛛。
- 上方以蛛后旁1～2个小型幼蛛符号与生命刻度显示，复用现有毒蛛素材；不增加大面积敌方背包UI。伤害／持续状态／反击记录目标和来源，避免本体状态穿透被当成攻击错误。

## 7. 技能预告与状态UI

- 敌人名旁显示职业图标和克制／被克制关系；点敌人可看生命、攻击、防御、速度、技能时机和被动。不新增常驻长文字提示。
- 蓄力／吐息／召唤预告只放在敌人附近一个短标记，显示“下次行动：重击／吐息／孵化”。预告在准备动作实际完成后出现，不抢占下方历程／背包。
- 双方血条旁用小图标与剩余回合显示护盾、毒、灼烧、减速、破甲。状态详情在点击时查看，不新增独立分区框。
- 狂暴显示一枚红色标记和当前增伤百分比；第14轮预警不增加确认按钮。Boss50%阶段仅短动画和一条日志，不暂停要求接受。
- 历程继续保留遭遇、结果、收益；战斗细节通过战斗日志／详情查看，不为每次毒跳伤插入新的节点年份。

## 8. 实施与验证边界

1. 用统一Combatant／技能定义／伤害事件支持双方，无论来源是物品、共鸣、典籍还是敌人技能；每个来源有唯一ID、施法者、实际目标、计时与次数。
2. 玩家状态增加受毒／灼烧／破甲模型，敌人增加护盾与有限治疗；双方伤害类型真实生效，旧未使用的怪物trait改为技能定义或删除，避免说明不等于实际行为。
3. 固定主动作选择器保证重击／吐息替代普攻，Boss阶段只触发一次、不重置倒计时；预告和动作状态可保存。
4. round≤15无狂暴，16／18／20／22边界倍率准确。速度变更、状态先杀、先手不同、暂停／倍速／跳过、重载必须得到相同行动次数和结果；不再保留旧31回合狂暴叠加。
5. 职业3×3矩阵双向验证，直接伤害／灼烧只乘一次，真实毒不乘克制，护盾治疗不受克制；不增加未知职业默认被克制或暗中跟随玩家职业的怪种调整。
6. 多源毒／灼烧、实际HP与护盾消耗、吸血仅实际HP、救援不复活、反击不递归、主动扣盾不触发破盾，按物品／共鸣已定边界统一处理。
7. 幼蛛数量、延迟激活、总召唤次数、实际目标与状态归属、死亡结束处理纳入验证；不能沿用合并幼蛛HP池而声称已实现独立目标。
8. 用三职业、三系混搭、三本典籍、优势／劣势怪物、前三短关和常规／极限章节模拟与真实浏览器验收；重点查看小怪3～6／阶段Boss6～12／额外试炼10～14目标回合是否达成，狂暴触发率与失败是否可理解。
9. 开局／掉落／共鸣候选／典籍／公会数值一起校准；构筑成长只在遭遇生成时取样，验证标准构筑、两倍／四倍实力、偏输出／偏防御构筑、卸装、拖动中间态、相邻布局变化和共鸣激活变化。剩余生命及战斗状态不改怪强度，生成后调整／读档不重新生成；强化仍应改善通过率与耗血。保存本局峰值和已生成遭遇，避免重新读档绕过成长。毕业评级只由培养成果确定，不因敌人职业临时修改评分。
