# 冒险公会素材库

以后处理美术先检索本库，优先复用现有资源。入口是 `library.json`：每件包含资源键、路径、分类、尺寸、透明信息、来源和校验值。可以按 `group` 或 `id` 搜索。不合适时先考虑裁切、等比缩放、翻转或组合，再决定补画。

| 目录／命名 | 用途 |
| --- | --- |
| `W-* / M-* / R-*` | 战士／法师／盗贼定稿物品 |
| `*-full / *-motion` | 人物、敌人立绘和动作 |
| `characters/heads/、hair/、hair-back/` | 男／女各4个头部、8种发型的前后层；128×192统一透明画布 |
| `characters/{warrior,mage,rogue}/` | 每职业4件衣物前层、4件绑定后层、4件下装；法师衣物为整件长袍，覆盖下装 |
| `tomes/` | 九本典籍96px透明图标，与正式典籍ID一致 |
| `ui/skins/` | 12种按钮／节点底板：常态、按下、禁用、选中、战斗、共鸣、结束等 |
| `ui/icons/` | 16个入口／资源／属性图标，统一48px画布 |
| `ui/controls/` | 返回、关闭、加减、继续、暂停、倍速、确认、锁定，32px |
| `ui/shelf-plank.png` | 书架木板，横向重复铺设 |
| 其余根目录PNG | 营地、遗迹与既有界面底板 |

按钮底板在源图19px处分九宫格，显示边缘通常8px、窄标签6px；圆节点只等比缩放。文字独立排版。图标使用 `image-rendering: pixelated`，不要裁掉主体；视觉图标与至少44px触控热区分别设置。

新UI来自用户确认的v19样稿，两张TapTap Maker图集拆分，未额外绘图；请求记录在 `ui/generation.json`。本地原图、透明图集、切图记录和32／64／96px入口图标变体仍保留在 `art-direction/pixel-v19-tomes-ui/`，游戏运行不依赖该历史目录。九本典籍与人物沿用已有资源，敌人来源见 `ENEMY-ART.md`。积分未核对，不写入推测消耗。
